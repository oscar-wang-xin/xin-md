# XIN-MD

微信公众号 Markdown 排版编辑器：**写作 → 实时预览 → 一键复制**，粘进公众号编辑器样式无损。

> 本项目基于开源项目 **「火星编辑器 (Mars Editor)」** 演进而来，感谢原作者的开源贡献 —— 详见 [致谢](#致谢)。

## 为什么样式无损

微信公众号编辑器会丢弃 `class` 与 `<style>`，只保留内联 `style`。因此本项目的主题系统
**不产出任何 CSS 类，只产出内联样式字符串** —— 预览里看到的排版，就是粘贴后的排版。

## 特性

- **实时预览**：编辑区与预览区滚动同步，改一个字就能看到成品
- **19 套主题**：浅色 / 深色分组，覆盖文艺、科技、内刊、机甲等不同气质（见[主题一览](#主题一览)）
- **排版密度三档**：紧凑 / 标准 / 宽松，「标准」即主题原始设计值
- **一键复制富文本**：直接粘进公众号后台，无需二次调整
- **图片本地存储**：粘贴 / 拖拽上传，存 IndexedDB，不依赖图床
- **扩展语法**：代码高亮、脚注、`==高亮==`、Obsidian `![[图片]]` 嵌入
- **草稿可以搬走**：导入导出 `.md` / `.txt` / `.zip` 备份包，正文还能导出 750px 长图

## 导入 / 导出

浏览器存储清掉就没了，所以草稿要能搬出去：

- **导入** `.md` / `.markdown` / `.txt`：每个文件建一篇草稿；`.zip`：按备份包整体还原
- **导出当前草稿 `.md`**：纯文本，图片引用保持 `![[名字]]`
- **导出全部备份 `.zip`**：草稿 + 图片原始文件 + `manifest.json`，可完整导回
  （zip 读写自己实现，压缩交给浏览器原生 `CompressionStream`，不引第三方库）
- **导出正文长图 `.png`**：750px 宽，正文直接画成一张图。走 `<foreignObject>` 序列化真实 DOM
  —— 正文样式全内联、图片全是 data URI，正好满足它的限制

## 图片粘贴

图片以 data URI 内嵌，**实测粘进公众号后台后原样保留** —— 带图文章不需要先传图床，
写完直接「复制到公众号」就行。

`tools/wechat-paste-test.html` 是当时用的实测页，四个用例（data URI 图片 / https 远程图片 /
图文混排 / 外链）各一个复制按钮，留着备用：微信哪天改了粘贴行为，复测一遍就知道。

## 技术栈

## 开发

```bash
npm install

npm run build    # 类型检查 + 生产构建
npm run preview  # 预览构建产物
```

## 部署

线上是 Cloudflare Pages 项目 `xin-md`，**直传部署，没有接 GitHub 自动构建** ——
推代码到 main 不会更新线上，必须跑一次：

```bash
npm run deploy   # 构建并发布到 xin-md.pages.dev
```

发完可以用 `npx wrangler pages deployment list --project-name xin-md` 核对，
最新一条的 Source 应当是刚推上去的 commit。

`dist/` 是纯静态产物（`base: './'` 相对路径），也可以直接丢到任意静态托管。

## 目录结构

```
xin-md/
├─ src/
│  ├─ App.tsx          # 应用外壳与状态编排
│  ├─ components/      # 界面组件（工具栏、编辑器、预览面板等）
│  ├─ markdown.ts      # Markdown → 全内联样式 HTML 渲染器
│  ├─ theme.ts         # 主题令牌系统 + 19 套主题定义
│  ├─ exchange.ts      # 草稿导入导出（含 zip 读写）
│  ├─ longimage.ts     # 正文长图导出
│  ├─ imagedb.ts       # 图片本地存储（IndexedDB）
│  ├─ clipboard.ts     # 复制富文本到剪贴板
│  └─ scrollSync.ts    # 编辑区 / 预览区滚动同步
├─ public/             # 图标（冷白机甲字标）
├─ tools/              # wechat-paste-test.html：粘贴行为实测页
├─ index.html
└─ vite.config.ts
```

## 相对上游的改动

以下是 XIN-MD 在上游「火星编辑器」基础上做的全部改动（上游原样存档在 `mars` 分支，可逐项对照）。

### 1. 更名

界面标题与印章字标、页面 `title`、favicon、导出备份文件名、长图与预览署名、npm 包名、
Cloudflare Pages 项目名，全部从「火星编辑器 / Mars Editor / `mars-editor`」改为
**XIN-MD / `xin-md`**。

### 2. 文章主题：12 套 → 19 套

- **移植 gzh-design-skill 的 6 套公众号排版风格**：摸鱼绿、红白色系、石墨极简、留白禅意、
  摸鱼票据、橄榄手记 —— 把该组件库的配色、字体、间距、装饰提炼为原生主题令牌
  （原组件库不入库，见 `.gitignore` 中的 `_ref/`）
- **新增冷白机甲**（`robot`）：机甲黑 / 灰蓝 / 冷白三色，硬边小圆角，深色机甲面板代码块

### 3. 编辑器外壳可换肤（新增功能）

右上角新增**色调选择器**，8 套色调一键切换，选择记在 `localStorage`：

| 色调 | id | 主色 |
|------|-----|------|
| 机械冷白（默认） | `robot` | `#5f6674` |
| 暖纸奶油（上游初代配色） | `warm` | `#d97757` |
| 商务蓝 | `business` | `#2f6fb2` |
| 薄荷绿 | `mint` | `#179c6b` |
| 墨水黑白 | `ink` | `#262626` |
| 葡萄紫 | `grape` | `#7c3aed` |
| 阿里橙 | `ali` | `#ff6a00` |
| 中国红 | `china` | `#c8102e` |

实现上把外壳配色抽成一组 CSS 变量（`--bg` / `--panel` / `--ink` / `--accent` 等），
按 `<html data-shell-tone="…">` 切换变量组；CodeMirror 的光标、行号、选区也改为引用这些
变量，所以换肤是整体的。**外壳色调只影响编辑器界面，与文章主题相互独立**，两者可自由组合。

### 4. 视觉识别

- **新图标**：冷白机甲三色绘制（冷白面板 + 机甲黑字标 + 接口槽），含
  `favicon.svg` / `favicon-32.png` / `apple-touch-icon.png` 三档
- `theme-color` 改为冷白 `#f2f4f7`
- **编辑器外壳默认配色**由暖纸底 + 陶土橙改为冷白机甲（暖色仍可在色调选择器里切回）
